# Changelog

## 0.3.1 — S2b-a.1 empirical coherence and dependence frontier

- Added a typed, source-by-source unit-of-observation audit.
- Added non-fitted body, tail, round-weight and below-1x interpretation tests.
- Added the Gaussian rho 0.00–0.40 frontier, guarantee breakpoints and large-N
  saturation analysis.
- Added 100,000-path correlated winner-deletion tests and Gaussian, Student-t,
  macro-mixture and sector-factor model-risk comparisons.
- Preserved the V1 config and inputs byte-for-byte; no central marginal V2 was
  invented from underidentified public aggregates.

## 0.3.0 — S2b-a empirical terminal marginals

- Added empirical source registry and aggregate constraint files.
- Added an empirically constrained terminal mixture with explicit body, tail and dependence model-risk variants.
- Added Pareto survival-tail beta calibration from 10x/50x aggregate constraints.
- Added top-winner dependence metrics, Monte Carlo convergence diagnostics, fund-level validation targets and S2b-a run artifacts.
- Added tests protecting S2a reproducibility while validating the empirical calibration layer.

## 0.2.0 — S2a vertical slice

- Replaced the three-point terminal outcome model with five YAML-defined synthetic outcome bands.
- Added the required eight portfolio sizes and five protection levels as a 40-point sweep.
- Added expected/median multiples, per-unit claim VaR and Expected Shortfall, extreme-winner counts and largest-investment concentration.
- Implemented multi-round founder-warrant dilution while keeping warrant value separate from claims.
- Added CLI seed override, exact same-seed numerical reproduction tests and five labelled figures.
- Expanded S2a acceptance tests and aligned documentation with the implemented conventions.

## 0.1.0 — first reproducible laboratory

- Added typed parameter provenance and YAML scenario loading.
- Added principal-floor, excess-of-loss and founder-warrant contracts.
- Added synthetic terminal Model A and minimal event-driven Model B.
- Added historical bootstrap interface without fabricated data.
- Added risk metrics, run manifests, summary reports and diagnostic figures.
- Added documentation, assumptions register, stress scenarios and tests.
- Added ADR-001 through ADR-005 with an index and links from the architecture documentation.
