# Limits of the evidence

- Public rounded aggregate financing statistics are not a row-level unique-company
  sample. The source/return definition mismatch remains unresolved.
- Body shape, extreme-tail severity, truncation and dilution are not uniquely fitted.
- Latent-factor dependence and selection advantages are hypothetical scenarios.
- Frozen S2a, S2b-a and the separate completed coherence V2 stage use threshold-conditioned ES; the selection-frontier implementation uses exact
  worst-probability-mass ES. Do not silently pool these conventions.
- The saved S2a manifest reports a dirty working tree. V2 has a clean source commit.
- No completed saved selection-frontier run was located. Its code and passing
  lightweight tests establish implementation, not the proposed numerical frontier.
- Zero sampled claims do not establish zero risk. 5,000-path screens have limited
  tail resolution; read Monte Carlo errors and tail counts in the V2 CSVs.
- Guarantor default, liquidity, capital cost, legal enforceability, insurance
  pricing, regulation and demand are not validated by this research.

Read the original model cards and saved V2 summary for stage-specific caveats.
