# Empirical calibration overview

S2b-a.1 adds the [unit-of-observation audit](unit_of_observation_audit.md) and
[empirical-coherence/dependence methodology](06_coherence_dependence_v2.md).
It preserves the frozen V1 marginal and treats de-duplication and alternative
dependence assumptions as model-risk scenarios, not fitted facts.

S2b-a adds an empirically constrained terminal investment-return model for the
principal-floor claim:

\[
C_T = \max(gK - NAV_T, 0).
\]

The target object is the posterior predictive claim distribution generated by
historically informed venture return evidence. This is not a guarantee quote,
insurance premium, regulatory capital model, legal wrapper, reinsurance
placement or full historical calibration.

The current empirical layer uses public aggregate constraints for investor-level
or financing-level return multiples and keeps them separate from model
parameters. The model then reports residual error, model-risk sensitivity and
unknowns rather than selecting a single "true" guarantee cost.

Run it with:

```bash
python -m invariant.cli run-empirical-terminal --config configs/calibrated_terminal_v1.yaml
```

The generated run contains the config, source snapshot, empirical constraints,
validation residuals, sensitivity ranking, results, manifest and diagnostic
figures.
